## ⚡ Overview

A performance-first, gamified personal developer portfolio designed to showcase engineering depth, systems architecture, and interactive software products. Built with modern web standards, featuring tactile analog aesthetic principles, dynamic state-driven easter eggs, and comprehensive search engine optimization.

---

## 🛠️ Architecture & Tech Stack

- **Framework**: [Next.js 15](https://nextjs.org/) (App Router, Server Components & Streaming)
- **Language**: [TypeScript](https://www.typescriptlang.org/) (Strict Mode)
- **Styling**: [Tailwind CSS v4](https://tailwindcss.com/) + Custom Design Tokens
- **Animations**: [Framer Motion](https://www.framer.com/motion/) (Micro-interactions, staggered viewport reveals & gesture physics)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Email Service**: [Resend](https://resend.com) Transactional API integration with graceful client fallback
- **Analytics & SEO**: Vercel Web Analytics, OpenGraph dynamic image generation, JSON-LD Schema.org semantic structured data

---

## ✨ Key Highlights

- **Hand-Crafted Warm Aesthetic**: Blends vintage typography (`Fraunces`, `Caveat`) with dark modern surface layers, responsive polaroid layouts, and custom code-card components.
- **Interactive Terminal**: Custom in-browser CLI terminal featuring commands (`help`, `whoami`, `projects`, `skills`, `sudo hire-me`) simulating UNIX-like environments.
- **Achievement & Gamification Engine**: Hidden visitor achievements, unlock toasts, confetti feedback, and secret developer interactions.
- **Featured Flagship Project**: Highlights **NextFlow** (Visual AI Workflow Orchestrator built with React Flow, dynamic node DAG execution, and persistent storage).
- **SEO & Performance Engineered**: Sub-second load times, 100% accessible semantics, static prerendering, and optimized font subsets.
